Git - это программа для отслеживания изменений в коде на вашем компьютере, а GitHub - это сайт и облачный сервис для хранения этого кода в интернете и совместной работы
Использованные команды: 
git status - показывает текущее состояние рабочего каталога и индекса в вашем репозитории
git diff - показывает различия между разными состояниями проекта в Git
git diff --staged - показывает разницу между подготовленными к коммиту изменениями и последним коммитом
