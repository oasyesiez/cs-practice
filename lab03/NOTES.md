git log  - показывает историю проекта, git show - детали одного конкретного обьекта, а git diff - разницу между двумя состояниями кода

git log -S  -  находит коммиты, в которых количество упоминаний указанной строки изменилось

git blame  -  находит и показывает автора, который последним изменил каждую конкретную строку в файле

git restore  -  восстанавливает файлы в вашем рабочем каталоге или индексе. То, откуда берутся файлы для восстановления, напрямую зависит от флага --source
Несохраненные изменения будут безвозвратно удалены(git restore) 
Все текущие правки в файле (и в рабочем каталоге, и в индексе) будут заменены версией файла из указанного коммита.(git restore --source)

git reset --hard  стирает коммиты из истории, а git revert создает новый коммит, который отменяет изменения старого.

Ветка — это подвижный указатель для текущей разработки, который сдвигается вперед с каждым новым коммитом, а тег — это постоянная и неподвижная метка, закрепленная за конкретным коммитом для обозначения релизов или версий.
